## Sobre
Este repositório contém o segundo projeto da unidade curricular de Inteligência Artificial, desenvolvido pelo Grupo 11.

O trabalho abrange a aplicação de três técnicas fundamentais de aprendizagem automática: **Regras de Associação**, **Classificação** e **Clustering**. Para cada técnica, foi realizada uma análise exploratória de dados (EDA) completa sobre datasets específicos, seguida da preparação e modelação dos dados.

## Datasets Utilizados

### 1. Regras de Associação - Fantasy Premier League
- **Dataset:** Fantasy Premier League 2024/2025
- **Link:** [https://github.com/vaastav/Fantasy-Premier-League](https://github.com/vaastav/Fantasy-Premier-League)
- **Notebook:** `eda_association_rules_dataset.ipynb`

### 2. Classificação - Body Performance Data
- **Dataset:** Body Performance Data
- **Link:** [https://www.kaggle.com/datasets/kukuroo3/body-performance-data](https://www.kaggle.com/datasets/kukuroo3/body-performance-data)
- **Notebook:** `eda_classificacao_dataset.ipynb`

### 3. Clustering - Formula 1 World Championship
- **Dataset:** Formula 1 World Championship (1950-2024)
- **Link:** [https://www.kaggle.com/datasets/rohanrao/formula-1-world-championship-1950-2020](https://www.kaggle.com/datasets/rohanrao/formula-1-world-championship-1950-2020)
- **Notebook:** `eda_clustering_dataset.ipynb`

## Instalação e Execução

1. Clone o repositório:
```bash
git clone https://github.com/your-repo/IA25_P02_G11.git
cd IA25_P02_G11
```

2. Crie um ambiente virtual e instale as dependências:
```bash
python -m venv venv
source venv/bin/activate  # No Windows: venv\Scripts\activate
pip install -r requirements.txt
```

3. Execute os notebooks Jupyter:
```bash
jupyter notebook
```
